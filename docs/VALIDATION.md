The 2026-10-17 staged review fixes conversion of cubical systems. Systems
with the same cover compare their branches on each common face, so branch
order, duplicate branches and differences outside a branch's face do not
reject valid reflexivity proofs. Four new roundtrip cases and one refusal
case in `test/pathtool.c` cover these rules, preserve term variables during
face substitution and keep distinct live paths unequal. The suite now has
30 path roundtrips and one system-conversion refusal. The three initial
regressions failed before the fix. `make -B check` passes with the fix.

The staged-change review closes a signature bypass in kit mode. Program
events, state constructors and state projections could take signature names
without passing through check_sig, for example `event Commitment`,
`state State := borrow`, or `state State := makeState (commit : Nat)`.
These now fail with REFUSE_SIG, including attempts to supply a slot through
a constructor or projection. Event checks use the event's own origin even
though events are installed while checking the trusted Out family.
Nine C regression cases in test/fronttool.c failed before the fix and pass
after it. Two positive cases preserve event-local field names and trusted
domain declarations. `make -B check` passes on the reviewed staged snapshot
with these fixes, including the clang syntax checks and all gate scripts.
